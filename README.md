# Long Live the Queen 非官方繁體中文 Mod

**公開測試版 0.10.2 · 適用 Windows / Steam 遊戲 1.5.16**

涵蓋第 1～40 週、結局、課程、服裝、人物資料及主要介面，共 5,447 組翻譯。保留原有美術風格，支援中文選單與全螢幕游標。

使用 AI 輔助翻譯、程式製作與校對，搭配玩家實玩及離線自動測試。仍待全文逐句人工校對與完整多路線驗證，歡迎回報用字、漏譯或排版問題。

## 下載與安裝

到本專案的 **Releases** 頁面下載 `LLTQ-TC-0.10.2-public.zip`，不要下載 GitHub 自動產生的 Source code 壓縮檔。

1. 儲存進度並完全關閉遊戲。
2. 解壓縮下載包，依內附 README.md 安裝；已有舊版者先依說明移除舊版。
3. 從 Steam 啟動遊戲；若顯示英文，在 Preferences → Language 選擇繁體中文。

本版只驗證 Windows 與遊戲 1.5.16，安裝器會檢查原版檔案相容性。
