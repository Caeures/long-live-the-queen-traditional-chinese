# Long Live the Queen 非官方中文漢化

提供繁體中文與簡體中文，適用 **Windows / Steam 遊戲 1.5.16**，需自行持有原版遊戲。

## 下載／下载

前往 [GitHub Releases](https://github.com/Caeures/long-live-the-queen-traditional-chinese/releases)，依版本說明選擇下載檔案。0.10.3 的檔名如下：

| 語言 | 安裝包 |
| --- | --- |
| 繁體中文 | `LLTQ-TC-0.10.3-public.zip` |
| 简体中文 | `LLTQ-SC-0.10.3.zip` |

請下載對應 ZIP，**不要下載 Source code**。同一遊戲目錄一次只能安裝一種中文版本；安裝另一種會替換原版本。

## 安裝／安装

1. 儲存進度並完全關閉遊戲。保存进度并退出游戏。
2. 將 ZIP 完整解壓縮。将 ZIP 完整解压。
3. 雙擊／双击 `Install.cmd`，輸入／输入遊戲安裝資料夾的完整路徑。
4. 從 Steam 啟動／启动遊戲。若仍顯示英文，在 Preferences → Language 選擇／选择中文。

繁體包內附 `安裝說明.txt`，简体包内附 `安装说明.txt`，包含自訂安裝路徑、更新、繁簡切換、移除與常見問題。

已用本安裝器安裝舊版者，可執行新版 `Install.cmd` 更新。手動安裝的舊版請先依說明備份並移除舊 Mod。
移除時關閉遊戲，執行 `Uninstall.cmd`。玩家存檔保留；不要刪除整個 game 或 translations 資料夾。

## 範圍與限制

- 0.10.3 包含第 1～40 週、結局、課程、服裝、人物資料與主要介面，共 5,454 組翻譯。
- 非官方公開測試版，使用 AI 輔助翻譯與校對；尚未完成全文人工逐句校對與完整多路線實玩。
- 簡體版由繁體版以 OpenCC 轉換並調整「你」的用字，尚未完成簡體全文人工校對。
- 0.10.3 補齊通關紀錄中發現的稱號、人物名稱與戰後軍營描述漏翻。
- 已有 HTML 紀錄不會自動改寫，可更新後在遊戲內重新匯出。
